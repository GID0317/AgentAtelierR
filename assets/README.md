# Assets are intentionally excluded

Original application resources are excluded. Do not commit original game images, audio, Spine skeletons, atlases, textures, animation data, or extracted application resources.

Exception: `branding/` contains the user-provided logo and application icon approved for inclusion in this repository. See `docs/APP_ICON.md` for the current icon source and regeneration steps. This exception does not authorize publishing other original game resources.

Use only self-created or properly licensed assets and follow `docs/RESOURCE_SETUP_AND_BUILD.md`.
