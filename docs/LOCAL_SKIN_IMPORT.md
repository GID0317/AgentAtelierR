# 本地皮肤和贴图导入

在聊天页打开“服装与姿态”，滚动到底部“本地皮肤与贴图”。导入文件只写入设备的应用私有目录，不上传服务器或 GitHub，不修改内置加密资源。

## 导入皮肤 ZIP

目前支持与现有莱莎动作系统兼容的 Spine 4.2 单页图集。ZIP 根目录或子目录应提供同名前缀的四个文件，例如：

```text
crf_skn_002_0002_01.atlas
crf_skn_002_0002_01.png
crf_skn_002_0002_01.skel
crf_skn_002_0002_01_gesture.json
```

点击“导入皮肤 ZIP”，通过校验后新增独立皮肤并切换显示，内置皮肤仍保留。当前不读取 ZIP 中的任意脚本或其他附带文件。没有独立预览图时显示空白，不把纹理图集当作预览。ZIP 和展开后的总数据均限制为 64 MB；不支持多页图集。

## 替换贴图

1. 先选择需要修改的皮肤，再打开选择页。
2. 点击“导入当前皮肤贴图”，选择 PNG。
3. PNG 必须与该皮肤原图尺寸相同，各部件的位置、旋转和 UV 排列也必须一致。尺寸相同只能说明图集大小兼容，不能自动判断绘制内容是否对应。
4. 导入后使用“原始贴图 / 导入贴图”切换，立即重新加载角色。原始骨骼和动作配置不变。

导入皮肤及贴图选择在重启后保留。不同皮肤各自保存一张替换贴图；重新导入替换图会更新当前皮肤的选择。导入资源不包含在聊天 JSON 存档中，换设备需重新导入。仅使用你有权使用的素材。
