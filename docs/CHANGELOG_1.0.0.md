# AgentAtelierR 1.0.0

版本：1.0.0+20，2026-09-16。

- 设置配置改用三级页面，统一半透明/液态玻璃材质、返回导航和表单底部操作区。
- 增加旧数据转换页面；先预览并保存转换后的本地文件，再由用户手动导入。
- 增加配置槽位、主题及帧率设置，完善本地存档和记忆管理。
- 增加地图采集、背包、炼金与任务相关实现。
- 更新角色动作、待机与语音表现；重复标点压缩仅用于 TTS 输入，保留原始消息。
- 角色模型和预览图通过本地加密构建脚本打包；仓库不包含密钥、明文或加密角色素材。
- 库肯岛保留放大的小地图，并将图片与地标同步右移；其他小地图恢复原比例。

## 验证范围

### 2026-09-17 待机、风动画和语音口型

- Android 与 PC 共用待机驱动补齐逻辑：兼容的本地导入皮肤从内置加密皮肤补齐缺失驱动，不覆盖已有服装动作或显式空绑定。
- 恢复待机动作幅度与风动画原速，保留室内外场景差异及平滑过渡；头部不随音节音量高频抖动。
- PC 使用请求的 WAV 音频计算实际响度；Android 对 MP3 等音频增加 MediaCodec 本地解码，只返回 20ms 音量窗口。
- 口型跟随真实停顿，取消对有音量数据的语音强制插入固定周期闭嘴，缩短开合响应时间。
- 验证：静态分析通过，258 项测试通过、9 项跳过；另外运行六套角色的原生物理/帧更新和导入资源测试。在线 TTS 的实际听感仍需设备试听。

### 2026-09-17 皮肤导入修复

- 服装选择页支持导入兼容的 Spine 4.2 单页 ZIP，以及为当前皮肤导入 PNG 并切回原始贴图。
- 修复解密资源表不可修改导致替换贴图加载失败的问题，改用独立副本覆盖纹理。
- 修复切换时旧资源包与新路径混用、异步加载结束后访问已销毁组件的问题。
- 导入资源仅保存在本地，不包含在源码仓库或聊天 JSON 存档中；详见 LOCAL_SKIN_IMPORT.md。
- 本次完整测试：256 项通过、9 项跳过；另已验证示例 ZIP 的原生 Spine 加载。
